# Real-text sentence-boundary eval

Self-contained held-out evaluation set for the sentence-boundary model on real
out-of-domain English text. Used as the regression gate for charstreamer
release wheels.

## Files

- `gold.jsonl` (~75 KB) — 4 corpora with embedded text and labeled boundary
  positions. Includes a Federal Register Rule, a Federal Register Proposed
  Rule, an excerpt of Pride and Prejudice, and a PubMed Central nephrology
  RCT. Total: 344 hand-labeled `true_breaks` (real sentence ends) and 26
  labeled `false_breaks` (positions where one or both segmenters claimed a
  boundary but should not have — abbreviations, decimals, Roman numeral
  section headers, etc.).

## Schema

```json
{
  "corpus": "fedreg-rule",
  "text": "...",                      // full text of this corpus excerpt
  "true_breaks": [123, 456, ...],     // byte positions that ARE sentence ends
  "false_breaks": [789, ...],         // positions that LOOK like ends but aren't
  "source_url": "https://..."
}
```

A "byte position" here is the byte index right after the last non-whitespace
character of a sentence. To compare a segmenter's predictions:

1. Run the segmenter on `record["text"]`.
2. Extract the byte position where each sentence span ends (with trailing
   whitespace stripped).
3. For each predicted position:
   - If it's in `true_breaks`: TP
   - If it's in `false_breaks`: FP
   - If it's in neither: skip (unlabeled)
4. For each `true_break` not predicted: FN.

## Provenance

Labels were generated by extracting every disagreement between charstreamer
0.1.5 and nupunkt 0.6.0 across the 4 corpora, then hand-correcting the
auto-labeler's results case by case. See
`logs/realtext-experiment/RESULTS.md` for the full process and audit trail.

The text excerpts are pulled from the URLs in `source_url`. Federal Register
content is public domain; PMC text is open-access (CC BY for the included
article); Pride and Prejudice is in the public domain.

## Usage

The canonical evaluator is `tools/abbrev-eval` (the schema is shared with the
abbrev eval). To run as a CI gate:

```bash
python -m charstreamer_realtext_eval \
    --gold data/eval/realtext/gold.jsonl \
    --min-f1 0.90
```

The 0.1.6 default model achieves F1=0.945 (P=0.994, R=0.901) on this gold.
